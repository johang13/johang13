#### [JOrder](https://github.com/johang13/JOrder) &nbsp; ![C#](https://img.shields.io/badge/C%23-239120?style=flat-square&logo=csharp&logoColor=white) ![.NET 10](https://img.shields.io/badge/.NET-10.0-512BD4?style=flat-square&logo=dotnet) [![Build and Test](https://github.com/johang13/JOrder/actions/workflows/build-and-test.yml/badge.svg)](https://github.com/johang13/JOrder/actions/workflows/build-and-test.yml)

A .NET 10 microservices platform for stock management, order processing, and invoicing. Built as a reference implementation for scalable, production-quality .NET systems — featuring JWT/OIDC auth, the Result pattern, EF Core interceptors, rate limiting, and Kubernetes deployment via a single `Makefile`.

#### [sdl-gamestep-demo](https://github.com/johang13/sdl-gamestep-demo) &nbsp; ![C](https://img.shields.io/badge/C-00599C?style=flat-square&logo=c&logoColor=white)

A lightweight SDL3 game-loop framework in C demonstrating a **fixed-timestep simulation with a decoupled render rate**. Includes hybrid CPU-friendly idle waiting, interpolation alpha for smooth rendering, and a clean callback contract separating update logic from rendering.

#### [sdl-test](https://github.com/johang13/sdl-test) &nbsp; ![C](https://img.shields.io/badge/C-00599C?style=flat-square&logo=c&logoColor=white)

A 2D explorer prototype in C using SDL3 + SDL3_image, built from local git submodules for fully self-contained, reproducible builds. Roadmap includes chunked infinite terrain with deterministic world-seed generation, streaming load/unload, and a world-space camera.
